What the timestamps mean

Verified exact

The timestamp is a chapter the creator defined, or a timestamped line they wrote in the description. It is the same number YouTube jumps to — nothing is inferred, and you can check any row against the video.

Inferred approximate

The video has no chapters, so topics are detected from how the speaker moves between subjects. The time is where that sentence truly begins in the captions; which sentences count as new topics is a judgment, so each row carries a confidence score and the sentence it came from.

Unavailable nothing claimed

No chapters and no usable captions. Rather than invent times, it says so. That refusal is the point — a made-up timestamp is worse than none.

There is no "99.99% accurate" claim here, because topic boundaries are not a ground-truth problem. What is exact is stated as exact; what is judgment is labelled as judgment. Measured numbers for the transcript detector are produced by npm run evaluate against a hand-labelled fixture.
